## Qué es

Una librería de **86 comandos** (`/showcase`, `/retoque`, `/quitarfondo`…) organizados en tres categorías. No son comandos reales de ningún chatbot: son plantillas de prompt que arman el texto completo por ti, listo para pegar en tu herramienta de generación o edición de imágenes con IA.

| Categoría | Comandos | Para qué |
|---|---|---|
| **Producto & Marketing** | 50 | Fotografía publicitaria, escenarios, formatos de campaña |
| **Retratos** | 18 | Edición de fotos de personas: fondo, iluminación, estilo |
| **Edición general** | 18 | Restaurar, colorizar, corregir, limpiar cualquier foto |

## Cómo se usa

1. Describe el sujeto de tu foto una vez.
2. Busca o filtra un comando (`/neon`, `/headshot`, `/upscale`…).
3. Copia el prompt generado y pégalo junto a tu foto en tu herramienta de IA.

## Stack

HTML, CSS y JavaScript sin dependencias ni build step — un solo archivo (`index.html`). Tipografías vía Google Fonts (Archivo + JetBrains Mono). Desplegado en [Vercel](https://vercel.com).

## Desarrollo local

```bash
git clone https://github.com/Tradester101/fotocomandos.git
cd fotocomandos
open index.html
```
